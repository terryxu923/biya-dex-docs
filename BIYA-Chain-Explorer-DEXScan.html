Biya Chain API 文档

                    
Biya Chain 提供了一套完整的 API 用于与区块链网络交互。通过我们统一的 API 平台访问账户信息、区块、交易等数据。

                


                
                

                    
快速开始

                    
    
                        
  1. 选择 API: 从下方可用的 API 中选择
    2. 
                        
  2. 获取 API 密钥: 获取身份验证凭据
    3. 
                        
  3. 发起请求: 开始与 Biya Chain 网络集成
    4. 
                    

                


                
                

                    
                

            


            
            

                

                    
                        
                    
                    基础 URL
                

                
所有 API 请求应发送到：

                

                    

                        
                    

                    

                        
https://explorer.biya.io

                    

                

            


            
            

                

                    
                        
                    
                    身份验证
                

                
所有 API 接口都需要使用 Bearer Token 进行身份验证。请在请求头中包含您的 API 密钥：

                

                    

                        
                    

                    

                        
Authorization: Bearer YOUR_API_KEY

                    

                

                

                    
⚠️

                    

                        
安全提示

                        
请妥善保管您的 API 密钥，切勿在客户端代码或公开仓库中暴露。

                    

                

            


            
            

                

                    
                        
                    
                    如何获取 API Token
                

                
                
                
您需要先注册账户并登录，然后在个人中心创建 API Token。以下是详细步骤：

                
                

                    

                        
1

                        

                            
注册账户

                            
点击页面右上角的「注册」按钮，填写邮箱和密码完成账户注册。

                        

                    

                    

                        
2

                        

                            
登录账户

                            
点击页面右上角的「登录」按钮，使用注册的邮箱和密码登录。

                        

                    

                    

                        
3

                        

                            
创建 API Token

                            
登录后点击左侧「Dashboard」进入控制面板，点击「创建密钥」按钮。

                        

                    

                    

                        
4

                        

                            
复制并保存 Token

                            
Token 创建成功后会显示一次，请立即复制并安全保存。之后将无法再次查看完整 Token。

                        

                    

                    

                        
5

                        

                            
使用 Token 调用 API

                            
在 API 请求的 Authorization 头中添加您的 Token，格式为：Bearer YOUR_API_TOKEN

                        

                    

                


                
                

                    前往登录
                    
请在区块链浏览器首页登录后创建 API Token

                


                
                

                    
                    

                    
                    
                    

                        

                            

                                
                            

                            

                                
您已登录

                                
请点击左侧「API 密钥管理」或前往 Dashboard 创建和管理您的 API Token。

                            

                            
                        

                    


                    

                        
💡

                        

                            
使用说明

                            
在 API 请求的 Authorization 头中添加您的 Token，格式为：Bearer YOUR_API_TOKEN
